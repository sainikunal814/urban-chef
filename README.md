# Urban Chef — Premium Kitchenware Store

A luxury kitchenware storefront built with React, TypeScript, Tailwind CSS, and Vite.

## Features

- Responsive eCommerce landing page for premium stainless steel cookware
- Interactive product cards, quick view, cart drawer, and checkout modal
- Modern UX powered by Tailwind CSS and motion animations

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Start the development server:
   `npm run dev`
3. Open the app in your browser at the URL shown in the terminal.

## Build

- Create a production build: `npm run build`
- Preview the production build locally: `npm run preview`

## Notes

- No special environment variables are required for this storefront.
- The app is configured to run on Vite with React and TypeScript.
